      <p style={{ color: "#E5E1D8", margin: 0 }}>
        <strong>quecto</strong> is the <a href="https://en.wikipedia.org/wiki/Metric_prefix" target="_blank" rel="noopener noreferrer" style={{ color: "#E5E1D8" }}>SI metric prefix</a> for 10⁻³⁰, the smallest unit in the metric system. If kilo is 10³ and quecto is 10⁻³⁰, this project lives at the extreme: a universal harness built from the smallest possible composable units, and the proof that smallest scales all the way up to a full coding agent. Two crates, one philosophy: <strong>quecto</strong> is the core, taking a prompt, running it through any OpenAI-compatible LLM (cloud or local), and returning the output, buffered or streamed. One job, zero opinions. <strong>quecto-agent</strong> is the coding agent built entirely on top of it: multi-step tool use, file edits under approval, a hard-denylist sandbox, verification gates, and session persistence, all in a 3.3 MB binary with no async runtime.
      </p>
